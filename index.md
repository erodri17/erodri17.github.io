I work in operations, where a lot of the job is routine work that has to be
done the same way every time. I write scripts and small desktop tools that take
the repetitive steps out of that work, and I document the processes so the next
person can run them without guessing.

#### What I work on

- **PowerShell automation.** Scripts for file handling, scheduled jobs and
  system checks, written to one standard so they are easy to read and support.
- **Everyday utilities.** Small Windows tools for searching files, comparing
  text, keeping reusable snippets and running checklists.
- **Process documentation.** Procedures and runbooks that are short, current
  and written for the person doing the task.
