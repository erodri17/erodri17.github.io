I work in operations, where much of the job is routine work that has to be done the same way every time. I build the scripts and desktop tools that take the manual steps out of that work, and I write the procedures that let someone else run it.

What I work on

  • Automation

    PowerShell scripts for file handling, scheduled jobs and system checks, written to one standard with logging and clear errors.

  • Desktop tools

    Small Windows utilities that each do one job: move files safely, compare data, watch for problems.

  • Documentation

    Procedures and runbooks that are short, current and written for the person doing the task.

Selected tools

I maintain a suite of sixteen Windows desktop tools built in PowerShell with Windows Forms. A few of them:

  • File Transfer Console Copies folder trees with a preview first, verifies every file by SHA-256 and keeps a journal so a failed run can be retried.
  • CSV Reconciliation Workbench Compares two CSV files on composite keys and reports duplicates, added and removed rows, and cell-level differences.
  • Integration Monitor Checks file age, folders, local services and TCP ports from a single XML configuration.
  • Folder Intake Validator Tests incoming files against name, type, size and CSV rules, reports rejections and quarantines them after review.
  • Log Explorer Tails large log files with text and severity filters, auto refresh and export.
  • Checklist Runner Runs text-file checklists with time-stamped ticks and notes, and saves a record of each run.
